> ABOUT HAZARD BALL                                      <
==========================================================
 Hazard Ball is a highly fun and addictive real-time arcade puzzle game for any age group.
You find your fate as a ball trapped within a labyrinth realm, finding your way to the exit is not as easy as it sounds, with many types of hazards and puzzles standing in the way, this game requires skill and patience!
Explore 20 huge levels spread over 5 worlds, or chose to play with a friend with 10 co-operative missions and 10 battle arenas!  Also featured is a free level editor for unlimited game play.  You can even try a hand at other levels created by other players from the website!

> CONTROLS                                               <
==========================================================
- Player 1

 Keyboard
 --------
 ARROW KEY UP        = roll up
 ARROW KEY DOWN      = roll down
 ARROW KEY LEFT      = roll left
 ARROW KEY RIGHT     = roll right
 RIGHT CTRL          = action
 RIGHT SHIFT         = booster

 Mouse
 -----
 MOUSE UP            = roll up
 MOUSE DOWN          = roll down
 MOUSE LEFT          = roll left
 MOUSE RIGHT         = roll right
 LEFT MOUSE BUTTON   = action
 RIGHT MOUSE BUTTON  = booster

- Player 2

 Keyboard
 --------
 'W'                 = roll up
 'S'                 = roll down
 'A'                 = roll left
 'D'                 = roll right
 LEFT CTRL KEY       = action
 LEFT SHIFT KEY      = booster

 Joystick
 --------
 JOYSTICK UP         = roll up
 JOYSTICK DOWN       = roll down
 JOYSTICK LEFT       = roll left
 JOYSTICK RIGHT      = roll right
 JOYSTICK BUTTON 1   = action
 JOYSTICK BUTTON 2   = booster

Note: In a single player game you may chose to use ANY of Player 2's control methods.

Ingame Functions
----------------
F1     toggle music
F2     toggle soundfx
F12    display FPS
-/+    resize viewport
ESC/P  pause menu


==========================================================
> HOW TO PLAY                                            <
==========================================================
Venture your way through each level avoiding hazards and solving puzzles.  Each level is a unique challenge and some can require great maneuvering skills.  Included is a tutorial mode where you can practice controlling the ball and become familiar with how the mechanics of the game work.

There are two methods of scoring.  Racing your way to the Exit Lifts to make the fastest possible times or by carefully collecting as many gems as possible to score the highest points.

To help you along the way you have the following abilities:  Booster to speed up the ball, Regenerators to rescue the ball from falling, Construction Blocks to build bridges and patch holes.

In two player modes Land Mines are available.  In a co-operative mission these can come in use to blast through walls, whilst having the Fire Protection of course, but in a battle arena Mines can be a deadly weapon to use against each other.

Using the Booster
-----------------
* Hold down the booster (see controls)
* Whilst the booster is pressed guide in the direction required. Extra acceleration will be applied to the ball and your booster will drain 
* Release Button B to stop boosting 

Using a Regenerator
-------------------
If you have lost control and fallen off the edge, during the fall quickly press your action button once and you will be regenerated back on the platform.

Using a Construction Block
--------------------------
* When approaching a gap, press down your action button.
* Whilst the action button is pressed guide the ball over the gap.  The construction block will be built under the ball, you can now release the action button.

Planting a Land Mine (2 Player Modes only)
------------------------------------------
Press, both, the booster button and the action button together to plant a Mine under the ball.  You have a second to move out of the Mine's space before it is armed.
