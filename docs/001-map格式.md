# 001 — `.map` 关卡格式

`Hazard Ball` 的关卡数据全部在 `DATA/*.map`，共 **127 张**（`level*.map` 单关、
`coop*.map` 双人、`menus.map` 标题画面）。格式为**小端**。

## 结构

| 偏移 | 类型 | 含义 |
|---|---|---|
| `0x00` | ASCII + `\n` | tileset 名（终止符 `\n`） |
| — | `u16 ×4` | `w`, `h`（地图格数）, `tw`, `th`（tile 像素尺寸） |
| — | ASCII + `\n` | 关卡显示名（终止符 `\n`） |
| — | `i16` | 关号 |
| — | `u8[w*h]` | **terrain 层**（地块类型编号） |
| — | `u16[w*h]` | **cells 层**（每格的动态属性/机关状态） |

`w`/`h` 是**格数**而非像素：如 coop10 为 `118 × 127`。

参考实现 `tools/hz.py::parse()`。

## terrain 编号

与出生点直接相关的两组：

| 编号 | 用途 |
|---|---|
| `2 3 / 4 5` | 玩家 2 出生点 2×2 地块（`2`=左上, `3`=右上, `4`=左下, `5`=右下） |
| `6 7 / 8 9` | 玩家 1 出生点 2×2 地块 |
| `50` | 普通地板（残缺缺口的填充值） |
| `32` | 墙 / 不可走 |

出生点的判据是「该编号集合**恰好**构成一个标准 2×2 排布」。
`tools/scan_ck.py` 用此判据扫描全部 coop 图。

## cells 层

`u16[w*h]`，紧跟 terrain 层。存放每格的机关状态（门、开关、传送带相位等），
与本仓库的两处修复无关，但格式已解出（见 `hz.py` 的 `cells` 字段）。
