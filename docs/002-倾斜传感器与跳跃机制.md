# 002 — Hazard.exe 逆向：Tilt and Roll 倾斜传感器机制

`Hazard.exe` = **Delphi + DirectInput 7 + DirectDraw**，32 位 PE。
所有地址基于 `IMG = 0x400000`。

|---|---|---|---|---|---|
| `.text` | `0x1000` | `0x42000` | `0x1000` | `0x42000` | XR |
| `.rdata` | `0x43000` | `0x2000` | `0x43000` | `0x15FA` | RW |
| `.data` | `0x45000` | `0x2D000` | `0x45000` | `0x2CDF8` | RW |

## 输入对象

`[0x44BC2C]` 指向一个运行时分配的对象（DirectInput 部分由 `0x408320` 初始化）：

| 偏移 | 内容 |
|---|---|
| `+0x000` | 键盘状态缓冲 256 字节（标准 DIK 扫描码，**空格 = `0x39`**） |
| `+0x100` | `IDirectInput7` |
| `+0x104` | 鼠标设备（`GUID_SysMouse`） |
| `+0x108` | 键盘设备（`GUID_SysKeyboard`） |
| `+0x10C` | 手柄设备（`EnumDevices(dwDevType=4)` 枚举得到，**无手柄时为空**） |
| `+0x160` | 手柄已获取标志 |
| `+0x161` | **本帧请求跳跃**标志 |
| `+0x163` | 空闲字节（本作用作按键边沿记录） |
| `+0x164` | 鼠标设备相关字段（**不是**状态缓冲指针） |
| `+0x110` / `+0x114` / `+0x118` | 手柄 **lX / lY / lZ** |

鼠标设备数据格式 `c_dfdx`；手柄配 3 轴、范围 `-255 ~ 255`。

## 倾斜传感器 = 手柄设备

游戏通过 `EnumDevices(dwDevType = 4 /* GAMECTRL */)` 枚举手柄，
回调（`0x4084C0`）取「第一个能 `CreateDevice` 成功」的设备，
把设备状态拷入全局 `0x44AD80`（`DIDEVICEINSTANCEA::tszProductName`）。

设备名还会与 `tiltsensor.txt` 中记录的名称比对（提示串
`USB TILT SENSOR NOT DETECTED` / `WITH A 3-AXIS TILT SENSOR`）。

## 跳跃的三个条件

```
0x408720  轮询手柄状态
          ├─ |某轴| > 50  →  mov byte [obj+0x161], 1     ← 闸门 1
          └─ 需 [obj+0x160] 手柄已获取（0x40E2BC 处每帧先清零再轮询，
                                          无手柄则整段跳过）

0x4075B0  消费 [obj+0x161]
          ├─ 闸门 2：|obj+0x118 (lZ)| > 240   ← 「猛然抬起」的真身
          ├─ 方向：取 obj+0x110 (lX) / +0x114 (lY)
          └─ 起跳冲量
```

**闸门 3（隐藏坑）**：`0x40759A` 处检测「当前是否正按着方向键」，
**按着就绕过整个跳跃判定** → 键盘玩家即使拿到标志也永远跳不了。

> `0x44BC58` / `0x44BC5C` 在每帧 recenter（`0x40EB10`）中作为乘数出现，
> 但**全文件无任何写入点**，恒为 `.data` 初值 `0`，
> 故 recenter 目标 = `X + 0.03 × 155 × 0 = X`，是**空操作**。

## 补丁

见 README「问题 2」与 `tools/build_patch.py`。

## 工具踩坑

- **capstone 线性反汇编找引用会失同步**：从段首线性 `disasm` 容易在遇到数据/未对齐
  指令处跑飞，把一整族函数误判为「无引用死代码」。
  必须改用**暴力扫描 `E8`/`E9` 相对调用**（`tools/relcall.py`）。
- keystone 汇编器**标签前向引用**（`jge .label` 出现在 `.label:` 之前）
  会抛 `KS_ERR_ASM_SYMBOL_MISSING` 并**挂起进程**；须先定义后使用。
- `ks.asm()` 只接受 ASCII，汇编串内注释必须英文。
